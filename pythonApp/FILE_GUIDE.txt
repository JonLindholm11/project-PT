  python nuzlocke_tracker.py --log-file test_output.log --process-existing
  
  # Test backend (after you implement it)
  python nuzlocke_tracker.py --test --api-url http://localhost:5000/api
  
  # Start monitoring
  python nuzlocke_tracker.py --log-file /path/to/emulator.log

💡 KEY INSIGHT
───────────────────────────────────────────────────────────────────────────
  The Python app is a BRIDGE, not a database!
  
  Lua Script ──→ Python Parser ──→ .NET Backend ──→ Your Database
                 (This tool)      (You build)
  
  No SQLite, no SQLAlchemy, no ORM - just HTTP POST to your API!
